# Data Schema Artifacts

This directory documents the canonical schema exports derived from the
`proto/` module. Generated artifacts are emitted under `../gen/` by the Buf CLI
and grouped by serialization format.

- `gen/protobuf/` – canonical Protobuf definitions exported via
  `buf export proto --output gen/protobuf`. Each schema version mirrors the
  package hierarchy and includes modularized `*.proto` files plus a compiled
  `descriptor.bin`.
- `gen/jsonschema/` – machine-readable JSON Schema artifacts generated by the
  Buf `protoschema-jsonschema` plugin. Both per-message schema files and
  bundled variants (`*.schema.json`, `*.jsonschema.json`, and corresponding
  `.bundle.json`) are emitted for downstream validation tooling.

To refresh the materialized schemas after modifying sources:

```bash
buf export proto --output gen/protobuf
buf generate proto  # produces gen/python/… and gen/jsonschema
buf build proto -o gen/protobuf/cryptofeed/normalized/v1/descriptor.bin
```

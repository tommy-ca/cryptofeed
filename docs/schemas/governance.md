# Schema Governance

This document tracks processes for schema releases, feedback triage, and Buf
Schema Registry (BSR) monitoring.

## Roles

- **Schema Stewards:** Own Cryptofeed dataclass definitions and approve changes
  that impact canonical fields.
- **Release Manager:** Coordinates Buf module publication and documentation.
- **Consumer Liaisons:** Monitor BSR feedback, downstream tickets, and adoption
  metrics.

## Release Checklist

1. Inventory updated via `tools/schema_inventory.py` with no stale alerts.
2. Regression report generated by `tools/schema_regression.py` with zero
   mismatches.
3. Version bump staged in `proto/buf.yaml` and changelog entry drafted.
4. CI jobs (`buf lint`, `buf breaking`) green.
5. `tools/buf_publish.sh <version>` executed to push module to BSR.
6. Documentation updated (`docs/schemas/README.md`, migration notes, FAQs).
7. Announcement posted to relevant engineering channels.

## Feedback Loop

- Track Buf module feedback via `buf registry module ls dependencies` and
  support requests logged in the schema backlog (SLA: acknowledge within
  2 business days).
- Weekly review meeting covers open requests, regression metrics, and upcoming
  breaking changes.

## Metrics Dashboard

Recommended data points (collected via Buf CLI or API):

- Downloads per module version
- Active dependents
- Time since last release
- Regression mismatch count (from latest report)

Automate exports using:

```bash
buf registry module get buf.build/tommyk/crypto-market-data --format json
```

## Breaking Change Policy

- Major version bump required for incompatible schema changes.
- Migration guide must include:
  - Updated field mapping table
  - Impacted downstream teams
  - Rollback strategy

## Issue Escalation

- Severity 1 (production outage): immediate pager escalation, schema steer
  meeting convened within 4 hours.
- Severity 2 (blocking adoption): issue owner assigned, resolution target 2
  business days.
- Severity 3 (feature request): triage during weekly review, schedule based on
  roadmap capacity.
